# AI 柜类试摆助手：实现说明

## 产品范围

- 用户上传一张真实家居场景图和一张柜类产品图，或跳过真实场景并选择虚拟空间风格。
- AI 自动判断产品是书柜、组合柜、斗柜、餐边柜或其他柜类。
- AI 给出摆放、保留、移除、书籍饰品和灯光建议，用户可以编辑方案或通过聊天补充要求。
- 用户勾选后才允许添加人体模特。
- 每次生成一张场景主图，并排版成固定的 1080 × 1440 家居海报。

## 工作流

```text
场景图（可选）+ 柜体产品图
  → AI 场景与产品分析
  → 柜体前景提取
  → AI 摆放和陈设建议
  → 用户确认或补充要求
  → 按确认清单清理场景
  → AI 生成无文字场景主图
  → 自动质检
  → Canvas 合成完整海报
  → 保存到 SaaS 图片记录
```

## 关键约束

- 不要求用户输入产品真实尺寸，也不在海报文案中介绍尺寸。
- 书柜和斗柜共用同一工作流，差异由 AI 产品身份分析处理。
- 目标柜体的模块、门板、抽屉、层板、玻璃、柜脚、颜色、材质和木纹需要保持。
- AI 自动在开放格、玻璃柜和台面安排书籍、陶瓷、艺术摆件与生活物品。
- 原场景只清理确认方案 `remove` 中明确列出的内容。
- 图片模型只生成纯场景，价格和中文文案由程序排版，避免模型生成错字。

## 海报结构

- 上部：AI 生成的家居场景主图。
- 场景右下：系列、产品名和可选价格。
- 下部：`About me`、AI 生成的中英文介绍及柜体产品小图。
- 输出尺寸：1080 × 1440 JPEG。

## 本地配置

本地真实 API 配置保存在 `.env.local`，该文件必须持续被 `.gitignore` 忽略。对外只提交不含密钥的 `.env.example`。
